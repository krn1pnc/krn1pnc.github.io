Codeforces 2217C Grid Covering

nnn 或 mmm 小于 2 的情况可以讨论掉，以下分析默认 n,m≥2n, m \ge 2n,m≥2．

能遍历所有格子的一个必要条件是，每个格子的 xxx 和 yyy 坐标都能被取到，容易发现这个等价于 nnn 与 aaa 互质且 mmm 与 bbb 互质．

考虑一个简化的情况．我们将一次 xxx 方向移动和一次 yyy 方向移动称作一组移动，考察整数组移动能到达的格子．由上述的分析可得，xxx 坐标的周期是 nnn，yyy 坐标的周期是 mmm，容易知道坐标序列 (x,y)(x, y)(x,y) 的周期是 lcm(n,m)\mathrm{lcm}(n, m)lcm(n,m)．那么当 gcd⁡(n,m)=1\gcd(n, m) = 1gcd(n,m)=1 时，仅仅考虑整数组移动，xxx 和 yyy 坐标的组合就可以取遍所有情况，这显然是合法的．

接下来考虑 gcd⁡(n,m)≠1\gcd(n, m) \not= 1gcd(n,m)=1 的情况．若能遍历所有格子，能到达的状态数至少要是 nmnmnm．但能对状态进行贡献的，只有整数组移动和在其基础上某个方向多一次移动构造出的坐标序列，能构造出的状态数至多只有 2lcm(n,m)2 \mathrm{lcm}(n, m)2lcm(n,m)．若 gcd⁡(n,m)>2\gcd(n, m) > 2gcd(n,m)>2，那么总状态数不可能大于 nmnmnm．故只用讨论 gcd⁡(n,m)=2\gcd(n, m) = 2gcd(n,m)=2 的情况．

容易发现只有在两种方式构造出的坐标序列中有元素相同时，能构造出的状态数小于 nmnmnm．考察何时两个序列中有元素相同，不妨令 yyy 方向上多一次移动，可以构造出下列同余方程 sa≡ta(modn),sb≡(t+1)b(modm)sa \equiv ta \pmod n, sb \equiv (t+ 1) b \pmod msa≡ta(modn),sb≡(t+1)b(modm)，即 s−t≡0(modn),s−t≡1(modm)s - t \equiv 0 \pmod n, s - t \equiv 1 \pmod ms−t≡0(modn),s−t≡1(modm)．即存在整数 p,qp, qp,q 使得 s−t=pn=qm+1s - t = pn = qm + 1s−t=pn=qm+1，即 pn−qm=1pn - qm = 1pn−qm=1．由 Bézout 定理，这不可能成立，故两个序列中的元素两两不同，总状态数为 nmnmnm．故 gcd⁡(n,m)=2\gcd(n, m) = 2gcd(n,m)=2 的情况总是合法．

Codeforces 2217D Flip the Bit

可以发现，特殊位置划分出的连续段之间操作相对独立．或者说，我们在尝试抹平一个连续段的时候可以不对其他连续段造成影响．

考虑利用 Easy Version 中的方式计算出每个连续段被抹平需要的操作数．由于最终要求和特殊位置的初始值相同，可以发现我们从每个连续段的左边或者右边开始操作，所需的总操作数是一致的．

对于一个特殊位置，我们可以选择一个从它左边的连续段开始，到它右边的连续段结束的区间，进行一次操作．这可以同时扣除两个连续段的待操作数．若我们已经将一个连续段抹平，我们可以将其两端的特殊位置看做一个，进行类似上述的操作．

我们可以用一个更直观的方式来看这个过程：令第 iii 个连续段的待操作数是 aia_iai​，每个连续段可以和其他连续段建立至多 aia_iai​ 个匹配，任意匹配之间不交，或者不存在匹配 (a,b),(c,d)(a, b), (c, d)(a,b),(c,d) 满足 a<c<b<da < c < b < da<c<b<d，最小化未建立的匹配数．可以通过调整法证明，当不存在一个 aia_iai​ 大于 12∑ai\frac{1}{2} \sum a_i21​∑ai​ 的时候，最小的未建立匹配数总是 000．故答案为 max⁡{12∑ai,max⁡ai}\max\{\frac{1}{2} \sum a_i, \max a_i\}max{21​∑ai​,maxai​}

Codeforces 2220C Grid L

不妨令 n≤mn \le mn≤m．

由网格总边数可知，能够拼成 n×mn \times mn×m 网格的一个必要条件是 p+2q=(n+1)m+(m+1)np + 2q = (n + 1)m + (m + 1)np+2q=(n+1)m+(m+1)n．我们尝试找到所有满足这个要求的 (n,m)(n, m)(n,m) 对．记 p+2q=xp + 2q = xp+2q=x，有 x−m=(2m+1)nx - m = (2m + 1)nx−m=(2m+1)n，即

x−m2m+1=n\frac{x - m}{2m + 1} = n 2m+1x−m​=n

两边同乘 222 后加 111 可得

2x+12m+1=2n+1\frac{2x + 1}{2m + 1} = 2n + 1 2m+12x+1​=2n+1

枚举 2x+12x + 12x+1 满足要求的因数对即可．

然后这样写过不了样例，分析可知 ppp 可能不够大．考虑一字形的数量的约束，一个简单的构造可以在 p≥m−np \ge m - np≥m−n 时候给出一组解：考虑先用 L 形组成的上下三角拼成一个 n×nn \times nn×n 的网格，剩余的列用 nnn 个 L 和 111 个一字形构成．写了交上去发现是对的．

让我们尝试证明：p<m−np < m - np<m−n 的时候无法构造出一组解．每个 L 形能贡献一个横向边和一个纵向边，每个一字形可以贡献一个横向边或一个纵向边．横向边比纵向边多的部分需要用一字形补齐，这部分的数量是 m(n+1)−n(m+1)=m−nm(n + 1) - n(m + 1) = m - nm(n+1)−n(m+1)=m−n．这样我们就证明了 ppp 至少要是 m−nm - nm−n，并且给出了一组合法构造．
